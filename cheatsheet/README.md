# mpv-cheatsheet

Better version of [mpv-cheatsheet](https://github.com/ento/mpv-cheatsheet)

## Usage

- `?` - Toggle cheatsheet
- `j` / `DOWN` - Scroll down
- `k` / `UP` - Scroll up
- `l` / `RIGHT` - Next section
- `h` / `LEFT` - Previous section
- `+` / `-` - Zoom
- `/` - Search (type to filter, `ESC` to cancel, `ENTER` to lock results)

## Options

- `font` - Font name
- `font_size` - Font size
- `activation_key` - Key to toggle cheatsheet
