# Subtitle Sync

Get Precise values for comparing subtitle timings.

## Usage

- `Ctrl+1` - Mark first subtitle start time
- `Ctrl+2` - Mark second subtitle start time
- `Ctrl+3` - Calculate difference

## Options

- `key_mark_first` - Key to mark first subtitle start time
- `key_mark_second` - Key to mark second subtitle start time
- `key_calculate` - Key to calculate difference
